# Cosc410-PollingPredictions
Final Project for Cosc410 - Using Machine learning to predict election results based on polling data
This project seeks to understand and realize the possibilities for using machine learning and prior polling data to help predict future polling as well as predict election results better than traditional polling methods.
We ultimately found that our polling could match the predictive abilities of polls taken a week before elections by using sequences of polls taken much earlier.


All of the results and graphs in the presentation can be recreated by running the finalproject.py file and modifying the finalResult variable to determine if training on the election results or the final polling results

Next steps would be to further expand on the data trained on as some quirks of the data could be explained away or not by more data so it is important to see what changes when more data is used. on top of this, strict time away from election dependacies were not explored which might be crucial in understanding the true abilities of this model as opposed to the simple proof of concept shown in the presentation. On top of this including other data features like what pollsters published the polls to analyze efficacy of certain polling places.
